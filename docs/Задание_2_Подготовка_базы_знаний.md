# Задание 2. Подготовка базы знаний

## Вывод

Создана корпоративная база знаний из **41 документа** на основе русской вики
The Witcher, в которой все узнаваемые термины заменены на **смешные русские
имена и названия** (Геральт → Гаврила, Нильфгаард → Нищегаард, Скоя’таэли →
Белки). LLM не встречала такой мир при обучении, поэтому RAG проверяется честно:
ответ может прийти только из векторного индекса, а не из памяти модели.

Артефакты:
- `knowledge_base/` — 41 анонимизированный `.md` (по одному файлу на сущность);
- `terms_map.json` — словарь замен (**207 терминов**, оригинал → замена);
- `scripts/` — воспроизводимый пайплайн `fetch → anonymize → verify`.

## Выбор вселенной

| Параметр | Значение |
|---|---|
| Источник | `witcher.fandom.com/ru` (русскоязычная вики) |
| Лицензия | CC BY-SA (фандом) |
| Покрытие | персонажи, чудовища, магия/знаки, локации/державы, организации, расы |

Русский источник выбран по требованию: замены — русские, поэтому и исходные
тексты берутся на русском, без смешения языков.

## Метод подмены (логика анонимизации)

Ключ словаря — **основа** термина, значение — замена в **именительном падеже**.
Скрипт `scripts/anonymize.py` собирает один компилированный regex и заменяет
все вхождения за один проход:

```
\b(основа)(\w*)   →   замена (именительный)
```

Падежное окончание захватывается группой `(\w*)` и **отбрасывается**
(«стратегия номинатива»). Это покрывает все склонения одним правилом:

| Оригинал (любой падеж) | Замена |
|---|---|
| Геральт / Геральта / Геральтом | Гаврила |
| ведьмак / ведьмака / ведьмаков | ворожей |
| Нильфгаард / Нильфгаарда / нильфгаардский | Нищегаард |

Реализованные требования к корректности:
- **Longest-match-first** — ключи сортируются по убыванию длины: «Трисс
  Меригольд» срабатывает раньше «Трисс», «Дикая Охота» — раньше «Дикая».
- **Регистр** оригинала переносится на замену (`match_case`: UPPER/Title/lower).
- **Границы `\b`** отсекают подстроки внутри слов.
- **Многословные термины** («Каэр Морхен», «Старшая Кровь», «Школа Волка») и
  формы с апострофом («Скоя’таэли») заданы явными ключами.

**Trade-off.** «Стратегия номинатива» иногда даёт лёгкую падежную
несогласованность («встретил Гаврила» вместо «Гаврилу»). Это сознательный
компромисс: правило универсально для всех склонений и родов, гарантирует
полное удаление оригинала, а тексты остаются связными и читаемыми.
Альтернатива (точное склонение замены через `pymorphy3`) отклонена как тяжёлая
зависимость, не дающая выигрыша для задачи.

## Очистка текста (`scripts/fetch_pages.py`)

Особенности, выявленные эмпирически и учтённые в коде:

1. **API.** Расширение `TextExtracts` (`prop=extracts`) на Fandom отсутствует,
   поэтому используется `action=parse&prop=text` + очистка HTML через
   BeautifulSoup (берётся `div.mw-parser-output`, удаляются таблицы, инфобоксы,
   сноски, навигация, hatnote-сноски и вкладки).
2. **Служебные разделы.** Сбор текста прекращается на разделах «Примечания»,
   «Источники», «Галерея», «Появления» и т. п. — это убирает основной массив
   латинского «мусора» (авторы, названия книг/серий, ссылки).
3. **Латиница вырезается полностью.** Этимология, «Старшая Речь» (вымышленный
   эльфийский), цитаты на других языках узнаваемы как The Witcher; база должна
   быть на чистом русском — латинских токенов в `knowledge_base/` нет вовсе.
4. **Знаки ударения.** Вики проставляет ударения комбинирующим символом
   (`Ге́ральт` = `Г·е·U+0301·…`), который ломает сопоставление по `\b`.
   Снимаются **только** знаки ударения (U+0300/U+0301), при этом буквы «й» и «ё»
   (precomposed) сохраняются — полная NFD-нормализация здесь недопустима, так
   как разложила бы «й»→«и», «ё»→«е».

## Контроль качества (`scripts/verify_kb.py`)

Гейт завершается с кодом `1` при нарушении любого инварианта:
- документов ≥ 30;
- ни одного оригинального маркера The Witcher по стоп-листу (стоп-лист шире
  словаря и ловит косвенные маркеры; общие слова «старший», «чародейка»,
  «утопить» из него исключены, чтобы не давать ложных срабатываний);
- тексты читаемы (длина и доля словесных символов выше порога).

Помимо гейта применялся **независимый частотный скан** заглавных слов: он
последовательно выявлял просочившиеся вторичные имена (Фольтест, Калантэ,
Аваллак, Гвинт, «Сопряжение Сфер», «Дикий Гон» и др.), которые добавлялись в
словарь до сходимости. Текущий результат: `файлов=41, утечек=0`.

## Воспроизводимость

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/fetch_pages.py     # witcher.fandom.com/ru → raw_pages/*.txt
python scripts/anonymize.py       # terms_map.json → knowledge_base/*.md
python scripts/verify_kb.py       # гейт качества (ожидается «ЧИСТО»)
```

Папка `raw_pages/` (сырые узнаваемые тексты) в репозиторий **не коммитится**
(`raw_pages/.gitignore`): её попадание в репозиторий обесценило бы «честную»
проверку RAG. В дереве остаётся только пустая папка, чтобы пайплайн
воспроизводился из чистого клона. Файл `terms_map.json` лежит в корне, а **не**
в `knowledge_base/`, иначе индексатор Задания 3 проиндексировал бы словарь (с
оригинальными терминами) как контент.

## Известные ограничения

- Остаётся «длинный хвост» очень редких (≈1–2 вхождения) второстепенных имён и
  конланг-терминов. Они не позволяют уверенно атрибутировать вселенную на фоне
  массива смешных русских замен; при необходимости добавляются в `terms_map.json`
  с повторным прогоном `anonymize.py` + `verify_kb.py` (повторное скачивание не
  требуется).
- Падежная несогласованность из-за «стратегии номинатива» (см. trade-off выше).
